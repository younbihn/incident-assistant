# RB-004 성능 저하 대응

## 증상
- 오류는 거의 없는데 응답시간만 느려진다
- 상태코드는 200으로 정상이고 사용자만 느리다고 느낀다
- p95 응답시간이 평균보다 훨씬 크게 벌어진다

## 즉시 조치
1. 최근 배포 이력을 확인한다
2. 느린 쿼리 로그를 확인한다
3. 캐시 적중률을 확인한다. 캐시가 비면 응답이 급격히 느려진다
4. 트래픽이 평소 대비 증가했는지 확인한다

## 근본 원인 점검
- 인덱스가 사용되지 않는 쿼리가 있는지 실행계획을 확인한다
- 배치 작업과 시간대가 겹치는지 확인한다
- 메모리 사용량 추이를 확인한다
