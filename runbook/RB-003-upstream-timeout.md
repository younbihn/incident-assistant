# RB-003 외부 연계 타임아웃 대응

## 증상
- 응답시간이 타임아웃 설정값 근처에 몰려서 나타난다
- 504 상태코드가 반복된다
- 우리 서버 자원 사용률은 정상인데 실패한다
- 로그에 upstream did not respond 문구가 보인다

## 즉시 조치
1. 연계 대상 기관 시스템의 공지나 점검 일정을 확인한다
2. 연계 구간 네트워크 경로를 점검한다
3. 재시도 정책이 과도하지 않은지 확인한다. 재시도가 상대 시스템 부하를 키울 수 있다
4. 필요하면 해당 연계 기능만 일시 차단하고 나머지 서비스를 보호한다

## 근본 원인 점검
- 타임아웃 값이 상대 시스템의 평균 응답시간 대비 적절한지 확인한다
- 회로 차단기 패턴이 적용되어 있는지 확인한다
