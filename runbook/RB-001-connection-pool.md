# RB-001 커넥션 풀 고갈 대응

## 증상
- 특정 서비스의 응답시간이 평소의 10배 이상으로 증가한다
- 500 오류가 섞여 나오지만 전부 실패하지는 않는다
- 로그에 connection pool exhausted, active, idle, wait 같은 문구가 보인다

## 즉시 조치
1. 해당 서비스의 커넥션 풀 사용률을 확인한다
2. 장시간 열려 있는 세션을 조회해 유휴 트랜잭션을 찾는다
3. 긴급 시 해당 서비스만 재기동한다. DB를 먼저 재기동하지 않는다

## 근본 원인 점검
- 세션을 닫지 않는 코드 경로가 있는지 확인한다
- 커넥션 풀 최대값이 DB 최대 접속 수를 넘지 않는지 확인한다
- 느린 쿼리가 커넥션을 오래 점유하는지 확인한다
